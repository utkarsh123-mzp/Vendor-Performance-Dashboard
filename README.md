 🧑‍💻 Vendor Performance Dashboard

 📊 Project Overview

The Vendor Performance Dashboard is a Data Analytics and Business Intelligence project developed to analyze vendor sales, purchasing, profitability, stock turnover, and overall vendor performance.

The project uses Python for data analysis and Microsoft Power BI for interactive dashboard development.

 🎯 Objectives

- Analyze total sales and total purchases
- Measure gross profit and profit margin
- Identify top-performing vendors
- Identify top-performing brands
- Identify low-performing vendors and brands
- Analyze purchase contribution by vendor
- Evaluate vendor performance and stock turnover
- Analyze unsold capital
- Create an interactive and professional Power BI dashboard

 🛠️ Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- Microsoft Power BI
- DAX
- Git & GitHub

The dashboard provides insights into vendor and brand performance by comparing sales, profitability, purchase contribution, and inventory-related metrics.

1. Open the Jupyter Notebook to explore the data analysis.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Use the interactive dashboard visuals and filters to analyze vendor and brand performance.
